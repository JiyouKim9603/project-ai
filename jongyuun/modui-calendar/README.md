# MODUI Calendar AI v7 변경사항

- 날짜 범위 반복 일정 생성을 지원합니다.
- `17일부터 23일까지 9시에 운동 일정 추가해줘` → 17~23일 총 7개 생성
- `17일부터 23일까지 평일마다 9시에 운동 추가해줘` → 해당 범위의 평일에만 생성
- AI가 범위 요청을 첫날 한 건으로 잘못 축소해도 서버가 날짜 범위를 감지해 `create_event_range`로 보정합니다.
- 반복 일정의 제목, 캘린더, 알림, 설명을 각 날짜에 동일하게 적용합니다.
- 같은 날짜/시간/제목/캘린더의 일정이 이미 있으면 중복 생성하지 않습니다.
- 한 번의 반복 생성은 안전을 위해 최대 366일까지 처리합니다.

# MODUI Calendar AI v6 변경사항

- 일정 삭제는 더 이상 즉시 영구 삭제하지 않고 `일정 휴지통`으로 이동합니다.
- AI 단일 삭제, AI 전체 삭제, 일정 수정창의 직접 삭제 모두 휴지통을 사용합니다.
- 휴지통 화면에 삭제된 일정과 삭제된 캘린더가 함께 표시됩니다.
- `복구해줘` → 가장 최근 삭제 묶음을 복구합니다.
- `운동 일정 복구해줘` → 휴지통에서 해당 일정만 복구합니다.
- `전부 복구해줘` / `모두 복원해줘` → 휴지통의 삭제 일정을 모두 복구합니다.
- 전체 삭제한 여러 일정은 같은 batchId로 보관되어 한 번에 되돌릴 수 있습니다.
- 휴지통에서 일정별 직접 복원 및 영구 삭제도 가능합니다.
- 휴지통 비우기는 삭제된 일정과 캘린더를 모두 영구 삭제합니다.

# MODUI Calendar AI v5 변경사항

- 알림 변경을 일정 시간 변경과 완전히 분리했습니다.
- `10분 전으로 했는데 1시간 전 알림으로 바꿔줘`처럼 수정 지시가 여러 개면 마지막 지시를 적용합니다.
- 알림만 바꿀 때 일정의 날짜, 시작 시간, 종료 시간, 제목은 그대로 유지합니다.
- 직전 대화에 나온 일정 제목을 이용해 후속 알림 요청의 대상을 이어서 찾습니다.
- `전부`, `모두`, `전체`, `싹 다` 삭제는 전체 일정 삭제 전용 액션으로 처리합니다.
- 특정 캘린더명을 말하면 그 캘린더의 일정만 모두 삭제합니다.
- 추천/조회 요청은 읽기 전용으로 유지되어 일정을 변경하지 않습니다.

# MODUI Calendar AI v3

MODUI Calendar에 로컬 Ollama AI를 연결한 버전입니다. OpenAI API 키나 API 크레딧은 필요하지 않습니다.

## v3 핵심 변경

이전 버전의 정규식 기반 일정 문장 파싱을 제거했습니다.
이제 사용자의 자연어를 Ollama가 JSON Schema 기반으로 의미 분석한 뒤 앱이 검증하고 실제 캘린더에 반영합니다.

예시:

```text
19일 개인일정 캘린더에 9시 운동 추가해줘 알림은 5분전에 오게 켜주고
```

AI가 다음 의미로 분리하도록 설계되어 있습니다.

```text
작업: 일정 생성
제목: 운동
날짜: 2026-08-19
시간: 09:00~10:00
캘린더: 개인 일정
알림: 5분 전
```

따라서 `알림은 5분전에...` 같은 문장이 일정 제목에 섞이지 않도록 했습니다.

## 지원하는 자연어 작업

- 일정 생성
- 기존 일정 시간/날짜/제목/캘린더 수정
- 기존 일정 알림 변경 또는 해제
- 일정 삭제
- 캘린더 요약
- 일정 충돌 확인
- 빈 시간 추천
- 최근 대화를 이용한 후속 질문 처리

예:

```text
내일 오후 2시에 치과 예약 잡고 한 시간 전에 알려줘
디자인 리뷰를 오후 3시로 옮겨줘
운동 일정 알림 10분 전으로 바꿔줘
개발자 스터디 삭제해줘
다음 주 회의 잡기 좋은 시간 알려줘
```

## 안전한 적용 방식

```text
사용자 자연어
   ↓
Ollama 의미 분석 + Structured Output
   ↓
일정 작업 JSON
   ↓
Node 서버 검증
   ↓
React가 실제 일정 생성/수정/삭제
   ↓
실제 반영 성공 후에만 ✅ 완료 메시지 표시
```

AI가 말로만 "추가했습니다"라고 하는 문제를 막기 위해, 일정 작업이 있을 때는 Ollama의 완료 문구를 화면에 그대로 표시하지 않고 React에서 실제 반영된 결과만 표시합니다.

## Ollama 설정

`.env`:

```env
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=gemma3
```

모델 확인:

```bash
ollama list
```

`gemma3`가 없다면:

```bash
ollama pull gemma3
```

직접 모델 테스트:

```bash
ollama run gemma3
```

## 실행

```bash
npm install
npm run dev
```

브라우저:

```text
http://localhost:5173
```

## 알림

AI가 `5분 전에 알려줘`를 이해하면 일정의 `reminderMinutes=5`로 실제 저장합니다.

지원 예시:

- 정시
- 5분 전
- 10분 전
- 30분 전
- 1시간 전
- 1일 전
- 그 외 분 단위 값도 AI 작업에서는 저장 가능

브라우저 알림을 실제로 받으려면 브라우저의 알림 권한이 `허용` 상태여야 합니다. 권한이 꺼져 있으면 AI 결과 메시지에 경고가 표시됩니다.

## 참고

Ollama 응답은 `/api/chat`의 JSON Schema Structured Output을 사용합니다. 로컬 모델의 해석 품질은 사용하는 모델 크기와 PC 성능에 따라 달라질 수 있습니다.
